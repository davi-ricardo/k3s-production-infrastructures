# Storage atual do cluster K3s

## Visão geral

O cluster atualmente não possui PersistentVolumes (PV) ou PersistentVolumeClaims (PVC).

As aplicações utilizam principalmente volumes do tipo hostPath diretamente no nó
srv1309476.

### glpi-app

  /opt/glpi/glpi-prod/files

  /opt/glpi/glpi-prod/marketplace

### glpi-db

## Observações

Os caminhos acima representam dados e configurações atualmente utilizados
pelos workloads do cluster.

Não realizar migração, remoção ou alteração desses caminhos nesta etapa.

A migração futura de hostPath para armazenamento declarativo com PV/PVC deverá
ser planejada individualmente para cada aplicação e precedida por backup e
validação dos dados.
